# Technical tools

You will not need all of these — set up what your project uses.

- [Git & GitHub](git-github.md) for code sharing and version control
- [Stata](stata.md) and [R](r.md) for analysis
- [SurveyCTO](surveycto.md) for primary data collection
- [Overleaf](overleaf.md) for papers and reports in LaTeX
- [VS Code](vscode.md) as an editor for code and Markdown
- [AI agents](ai-agents.md) — what Georgetown provides, and what gui2de reimburses

For proprietary software, Georgetown staff should use the
[employee software webstore](https://sites.google.com/georgetown.edu/guemployeesoftwarewebstore/)
for installers and licence information.

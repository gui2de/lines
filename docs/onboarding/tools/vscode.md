# VS Code

[VS Code](https://code.visualstudio.com/) is an advanced text editor. It is optional, but useful if
you work across several languages.

- Edits any text file — Markdown, Stata do-files, R scripts, LaTeX.
- Runs code directly from the editor.
- Integrates with git/GitHub, and with Copilot and other [AI agents](ai-agents.md).

It is also the easiest way to edit this handbook if you would rather not use the GitHub web editor.

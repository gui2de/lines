# Files and folders

Ask your project manager or PI to add you to the relevant project folders — existing folders are
listed in the [gui2de folders list](https://docs.google.com/spreadsheets/d/1iq0d_jkqFv95JkLRjGV37CiFThAKxGvDZ8n-GPU7bdY/edit).
Below are some basic principles:

- We use **Georgetown Box** for data (including PII)
    - One Box folder per project
    - Some projects also include programmatic files on Box, depending on team and PI preference
    - Download [Box Drive](https://box.georgetown.edu/product-information/#box-drive) to sync data on your computer
- We use **Google Drive** for programmatic files
    - One Shared Drive per project
        - Some projects also have a second Shared Drive for admin documents only, not shared with partners or students
    - Shared Drives for common resources
        - [Students resources](https://drive.google.com/drive/folders/0AOcAPJXC9kX3Uk9PVA)
        - [Staff resources](https://drive.google.com/drive/folders/0ACnkSxk6TScxUk9PVA)
    - (optional) Download [Google Drive for Desktop](https://www.google.com/drive/download/) to sync programmatic folders to your computer

Box Drive and Google Drive do not download files onto your computer unless you ask them to sync a
folder for offline access, so they should not take up space on your laptop.

Once a project is running, how data is handled inside those folders is covered in
[data storage](../../research/data-management/storage.md) and
[workflow](../../research/workflow.md).

# Workflow & collaboration

How gui2de works together: where files live, which tools we talk in, and what we expect of each
other.

Before anything else, understand the [folder structure](folder-structure.md) — which platform
holds programmatic files, which holds data, and why we never keep two copies of the same thing.
Day-to-day conversation happens on [Slack](slack.md) rather than email, and meetings on
[Zoom](zoom.md). Our [professionalism standards](professionalism.md) set out the agenda, minutes
and response-time expectations that apply to everyone.

Ask your project manager or PI to add you to the relevant project folders.

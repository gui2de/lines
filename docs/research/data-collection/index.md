# Primary data collection

Running a survey, from questionnaire to clean data.

Work through [survey design](survey-design.md) before building anything — it covers coding the
form in SurveyCTO, and what changes are safe once collection has begun. Once data starts arriving, run
[high frequency checks](hfc.md) daily, and [audits and backchecks](audits-and-backchecks.md) on a
sample of completed interviews as an independent check on the data.

Phone surveys use the same pipeline, with a shorter instrument (see
[remote survey writing](survey-design.md#remote-survey-writing)) and
[case management](case-management.md) to track who still needs to be reached.
